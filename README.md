# پروژه کارنکس (KarNex) 🚀

یک وب‌سایت کاریابی و پلتفرم استخدام فول‌استک (Full-Stack) مدرن و کاملاً ریسپانسیو.

![اسکرین‌شات پروژه کارنکس](./public/Screenshot.png)

## 📌 درباره پروژه
کارنکس با هدف اتصال کارجویان مستعد به کارفرمایان معتبر طراحی شده است. این پروژه دارای رابط کاربری مدرن، حالت‌های تاریک/روشن، سیستم احراز هویت (JWT) و فیلترهای پیشرفته جستجوی شغل است.

## 🛠 تکنولوژی‌های استفاده شده
*   **فرانت‌اند:** React, TypeScript, Vite, Tailwind CSS, Zustand
*   **بک‌اند:** Node.js, Express, Prisma ORM
*   **دیتابیس:** PostgreSQL
